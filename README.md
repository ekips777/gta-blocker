# GTA 内容屏蔽助手

屏蔽中文互联网上的 GTA / 侠盗猎车手相关内容的浏览器扩展（Manifest V3，支持 Edge / Chrome 及其他 Chromium 内核浏览器）。

## 功能

- 关键词屏蔽：GTA、侠盗猎车手、R星、GTA6 角色与地名（露西亚、杰森、雷奥尼达、罪恶都市等 40+ 词）
- 站点适配：B站、微博、知乎、百度、贴吧、抖音网页版、小红书、头条、斗鱼、虎牙等
- 纯文本模式：不依赖站点结构，扫描页面可见文字直接拦截
- 整页拦截：详情页标题命中关键词时遮挡全页，可一键放行
- 主动搜索豁免：自己搜索时保留搜索框与页面框架
- 保守模式：只隐藏含关键词的最小文字块，不影响信息流加载
- 元素拾取：点击页面元素即可生成屏蔽规则
- 按网站停用 / 恢复本页显示 / 当日拦截统计

## 安装（开发者模式）

1. 下载本仓库（Code → Download ZIP）并解压
2. 打开 `chrome://extensions` 或 `edge://extensions`
3. 开启「开发者模式」→「加载已解压的扩展程序」→ 选择本目录
